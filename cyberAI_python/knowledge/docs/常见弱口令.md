# 常见弱口令（简单密码）汇总

> 用途：弱口令检测、账号口令安全加固参考
> 更新日期：2026-08-16

> 注意：可以通过企业查询等方式，查找该网页或该单位负责人的名字等信息和其电话号码，将其名字缩写与简单的弱口令结合，或名字缩写与电话号结合

## 一、纯数字类（最常见）

```
123456     123456789   12345678    1234567890
111111     000000      666666      888888
999999     123123      123321      1234567
987654321  112233      121212      1234
12345      123654      654321      102030
110110     10086       10010       5201314
1314520    520520      521521      147258369
1234567891 112358      5201314     a123456
```

## 四、管理员账号常用组合类

```
admin123    admin888    admin123456 admin@123
admin@1234  admin2023   Admin123    p@ssw0rd
p@ss123     P@ssw0rd    root123     admin000
admin111    admin2019   admin2020   admin2021
```

## 五、中文拼音 / 数字谐音类

```
woaini      aini        woaini1314  5201314
1314520     520520      a123456     z123456
q123456     nihao123    woaiwojia   wang123
zhang123    li123456    123456a     123456q
```

## 六、其他常见规律

```
账号名 + 123        ：admin123、root123、test123、user123
账号名 + 数字      ：admin1、admin666、admin888
单词 + 年份        ：admin2024、password2023
简单叠加           ：aaaaaa、aabbcc、111111、222222
特殊字符简单组合    ：admin!@#、abc@123、!@#$%^
```

## 使用提示

- 检测时优先覆盖前两类（纯数字、键盘规律），命中率最高。
- 中文字典建议结合**目标单位名称 / 员工姓名拼音 + 数字**自行补充。
- 弱口令不仅指长度短的密码，还包括：与账号相同的密码、默认密码未改、密码=用户名等。
